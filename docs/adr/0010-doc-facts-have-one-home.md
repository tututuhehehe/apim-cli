# ADR-0010：文档事实单一来源（Doc map 是唯一索引，守卫钉住）

- 状态：Accepted（2026-10-09）
- 来源：文档层 retro（同日的三个候选：SKILL 命令表漂移 / AGENTS.md 常驻体量 / 目录树与现实不一致）→ `.scratch/docs-single-source/` 十张票

## Context

同一件事曾经写在多处，而且**越读越像真的**，没人能从文件本身判断哪份更新：

- `AGENTS.md` 的约定 11 / 14 / 15 与 `docs/` 各讲一遍同一批约束；
- `.agents/skills/apim/SKILL.md` 手抄了一份 CLI 命令表 —— 停更后落后两个功能轴（`apim auth` 整块缺席、`provider add --kind` 没写），而它正是 agent 最先读到的那份；
- 约定 13 说客户端说明「写在客户端子模块的文档里」，`AGENTS.md` 的 Doc map 说 `docs/clients/*.md` —— 两处并存；
- 一条安装禁令（开发时别用某条 cargo 命令）在三份文档里被抄反了一次。

代码侧早就有守卫（fmt / clippy / test / MSRV / JS 语法检查），而文档侧**零守卫**：一个没有 guardrail 的仓库是制度性缺口，不是中立的默认值。

## Decision

1. **`AGENTS.md` 的 Doc map 是「每类信息只有一个家」的唯一索引**：每类信息一行，指向它的家；其它位置**只放指针**。
2. **长期文档都要能从 Doc map 走到**（最多一跳：Doc map 点到的算第一跳，被点到的索引文件再点名的算第二跳）。
3. 这条规则**由守卫执行，不靠自觉**：`tests/docs.rs`（集成测试二进制，跑 `cargo test` 即执行，同时搭上本地 `cargo test`、CI 的 `cargo test --all`、MSRV job 的 `--all-targets` 三条路径）——
   目录树 ↔ `src/` 双向、`apim help` 的命令面 ⊆ README、SKILL 不定义命令面、那条安装禁令只许待在它的家里、无孤儿文档、以及 `AGENTS.md` 的体量 ratchet（行数 + 字符数，只允许变小或保持）。
4. 已有专门家的细节，`AGENTS.md` 只留**一行硬约束 + 指针**；重复的那一份**删掉**，而不是「再加一个检查」。

## Consequences

- 改一处事实只需要改一个文件；想往 `AGENTS.md` 里加内容，得先回答「删什么」或者「挪到哪个家」（ratchet 顶着）。
- 守卫的定位要说清：它们是**子集 / 存在性**检查，能抓「发明了不存在的命令」「两份说法互相矛盾」「孤儿文档」「禁令被抄了第二份」，**抓不到遗漏**（少写一整块不会红）—— 所以本条的取向是**删掉第二份**，而不是「检查第二份」。
- 细节搬走之后，读 `AGENTS.md` 的人要跟着指针去 `docs/clients/*.md` 等家才拿到全貌：代价是「多一跳」，收益是常驻上下文从峰值 226 行 / ~21.5k 字符压到 **181 行 / ~12.5k 字符**（ratchet 钉住）。
- **与 `ADR-0007` 的边界**：ADR-0007 容忍的是**代码**重复（三处小重复，附动手触发条件）；本条管的是**文档事实**重复。以后不要拿 0007 来挡文档去重。
- **何时该重开**：某个家被证明放错了地方（例：`docs/provider-kinds.md` 其实该并进 `docs/clients/`）→ 移动它并更新 Doc map；或者守卫的**假红**多到让人开始绕过它 —— 那说明规则本身不成立，而不是守卫坏了。
